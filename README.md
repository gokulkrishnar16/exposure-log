# Exposure Log

**A browser-based image metadata forensics tool for discovering what a photo reveals about itself.**

Upload or drag & drop an image to inspect:

* Camera & device details
* Capture date & time
* Aperture, shutter speed & ISO
* Image dimensions & file information
* GPS coordinates & altitude
* Location visualization via Maps

### Key Feature

**Privacy-first:** Images are processed locally in the browser and are not uploaded to a server.

### Built With

`HTML5` • `CSS3` • `JavaScript` • `EXIF.js`

### Purpose

Created for **educational digital-forensics and privacy awareness**. It is intended for quick metadata inspection, not legal chain-of-custody analysis.

> **Know what your images reveal before you share them.**
